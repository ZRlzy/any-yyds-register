根目录 `main.py` 作为唯一启动点，通过 FastAPI lifespan 在进程启动时依次初始化数据库、加载所有 Platform 插件（`core.registry.load_all`）与 Provider 插件（`providers.registry.load_all`），并启动任务调度器、任务运行时与 Turnstile Solver 子进程；关闭时按相反顺序释放资源。各子模块通过清晰的边界契约协作：`domain_model` 定义跨层共享的 Pydantic/SQLModel 实体；`core_engine` 提供平台注册表、账号生命周期与执行器；`api_server` 暴露 REST 路由并由 `application_orchestrator` 聚合领域服务调用；`infrastructure_repositories` 实现持久化与运行时代码执行适配；`platforms` 与 `providers` 以装饰器自动发现方式被核心引擎装配；`background_services` 提供独立子进程（Turnstile Solver）并通过 HTTP 与主进程通信；`customer_portal_api`、`electron_desktop`、`frontend_app` 分别作为管理端后端、桌面壳与 Vite+React 前端，由 Dockerfile 多阶段构建将前端产物注入到 FastAPI 静态目录并通过 SPA fallback 路由访问。Docker 环境通过 `docker-compose.yml` 一次性拉起 8000（API/Web）、6080（noVNC 浏览器预览）、8889（Solver）三个端口，并以 SQLite 文件卷持久化数据。
