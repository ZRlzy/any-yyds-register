- 平台插件通过继承 `BasePlatform` 并定义 `name/display_name/version` 等类属性，再使用 `@register` 装饰器完成自注册。
- 平台能力以字符串 ID 列表声明于 `capabilities`，并通过 `capability_overrides` 覆盖标签、参数 schema 与 UI 提示，由 `CapabilityRegistry` 统一解析。
- 注册流程统一经由 `BasePlatform.register()` 分派到 `registration` 下的三种 Flow（browser/mailbox/oauth），平台只暴露 `build_*_adapter()` 钩子。
- 执行器类型（protocol/headless/headed）与验证码 provider 均从 `RegisterConfig.extra` 或外部 `ProviderSettingsRepository` 动态解析，而非硬编码。
- 跨模块共享的基础设施（DB、HTTP、代理、TLS、调度、生命周期）集中在 core 顶层文件，平台插件仅通过基类间接依赖。
