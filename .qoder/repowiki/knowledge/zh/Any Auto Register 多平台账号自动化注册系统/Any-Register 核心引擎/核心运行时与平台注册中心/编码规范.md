- 平台插件通过继承 `BasePlatform` 并声明 `name`/`display_name`/`capabilities` 等类属性，再由 `@register` 装饰器注册到全局注册表。
- 可插拔组件（执行器、身份提供者、验证码解决器）均采用 ABC 基类 + `create_*` 工厂函数 + 字符串 key 路由的模式，避免循环导入。
- 注册流程统一通过 `RegistrationContext` 传递上下文，并由 `*_Flow.run(ctx)` 编排 preflight、captcha/otp/link 回调与 worker 执行，适配器只关注具体步骤。
- 能力（capability）采用声明式定义：`capability_registry.STANDARD_CAPABILITIES` 集中描述 id/label/参数 schema/ui_hints，平台通过 `capability_overrides` 覆盖显示标签与参数。
- 数据库访问统一使用 `sqlmodel.Session(engine)` 上下文管理器，并以 `patch_account_graph` 增量更新 account graph 而非直接写字段。
- 日志输出通过 `BasePlatform.set_logger` 注入的 `_log_fn`，默认回退到 `print`，便于测试与上层替换。
