- 每个平台在 `plugin.py` 中定义一个继承 `BasePlatform` 的类，并通过 `@register` 装饰器暴露 `name`、`display_name`、`version`、`supported_executors`、`supported_identity_modes`、`protocol_captcha_order` 等元数据。
- 注册流程通过返回 `BrowserRegistrationAdapter` / `ProtocolMailboxAdapter` / `ProtocolOAuthAdapter` 来声明式组装 worker、result_mapper、otp_spec 与 oauth_runner，而非直接编写注册主循环。
- 结果对象统一映射为 `core.registration.RegistrationResult`，并将 token、cookies、workspace_id 等敏感字段放入 `extra` 字典，保持跨平台一致的数据契约。
- 平台特定逻辑（browser_register、protocol_mailbox、switch、payment 等）采用方法内 `import` 延迟加载，避免启动时依赖缺失导致整个模块不可用。
- `check_valid` 通过调用平台 API 校验账户有效性，并在失败时吞掉异常返回 `False`，使上层批量检查具备容错性。
- 平台动作通过 `get_platform_actions()` 声明式列出（id/label/params），再由 `execute_action` 或 `_execute_platform_action` 分派执行，参数使用 `{key,label,type}` 描述。
