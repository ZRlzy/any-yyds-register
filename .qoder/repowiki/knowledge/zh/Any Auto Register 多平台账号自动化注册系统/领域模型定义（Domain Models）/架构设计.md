本模块为纯数据契约层，不包含任何业务逻辑或 I/O 依赖，仅通过 Python dataclass(slots=True) 声明不可变风格的领域对象，供上层 service/infrastructure 复用。
- 按聚合域划分文件：`accounts.py`（AccountRecord/Command/Query/Stats）、`tasks.py`（TaskProgress/Summary/Event）、`proxies.py`（ProxyRecord/Create/BulkCreate/CheckSummary）、`actions.py`（ActionParameter/PlatformAction/ExecutionCommand/Result）、`task_logs.py`（TaskLogRecord）、`platforms.py`（PlatformDescriptor/PlatformCapabilities）、`platform_caps.py`（PlatformCapabilitiesUpdate）。
- 每个文件内以 `@dataclass(slots=True)` 统一建模，字段默认值使用 `field(default_factory=...)` 避免可变默认陷阱；可选字段统一用 `Optional[...] = None` 表示。
- 时间戳字段统一使用 `datetime` 类型并以 `created_at/updated_at/started_at/finished_at` 命名约定表达生命周期。
- 模块入口 `__init__.py` 仅保留 docstring，不对外 re-export，调用方需显式 import 具体类，保持清晰的包边界。
