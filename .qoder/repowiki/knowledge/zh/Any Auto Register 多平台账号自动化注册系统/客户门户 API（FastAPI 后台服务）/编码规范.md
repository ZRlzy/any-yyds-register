- 路由函数仅做参数解析与转发，实际业务逻辑委托给 `services` 下的 `AuthService` / `PortalService` 实例方法，保持路由薄而服务厚。
- 所有需要鉴权的接口通过 FastAPI `Depends(get_current_user)` 注入当前 `PortalUser`，管理员接口额外叠加 `Depends(require_admin)` 进行角色白名单校验。
- 数据库会话统一通过 `Depends(get_db_session)` 获取，并在路由函数中以命名参数声明，由 FastAPI 自动管理生命周期。
- 模型字段普遍使用 `default_factory=utcnow` 生成 UTC 时间戳，新增记录时显式设置 `created_at`/`updated_at`，更新时同步刷新 `updated_at`。
- JSON 扩展字段（如 `metadata_json`、`payload_json`、`credentials_json` 等）以 `_json` 后缀列名存储字符串，读写时在 service 层用 `json.dumps/dumps(..., ensure_ascii=False)` 与 `json.loads` 转换。
- 对外响应统一通过 service 内部的 `_serialize_*` 私有方法将模型对象序列化为字典，避免在路由层直接暴露模型字段。
