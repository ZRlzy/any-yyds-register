采用典型的分层架构：`main.py` 通过 `lifespan` 钩子调用 `bootstrap.initialize_runtime` 完成数据库建表与种子数据注入；路由层按业务域拆分为 `app/routers/{auth,app_api,admin,payment}.py`，统一挂载到 `/api` 前缀；依赖注入集中在 `app/deps.py`，提供 `get_db_session`、`get_current_user`（基于 Bearer Token）和 `require_admin` 三个核心依赖；业务逻辑封装在 `app/services/{auth,portal}.py` 的类中，每个方法接收 `Session` 并直接操作模型；数据模型定义在 `app/models.py`，全部继承 `SQLModel(table=True)`；配置集中于 `app/config.py` 的 `Settings` 类，通过环境变量注入；安全能力（密码 PBKDF2-SHA256 哈希、HS256 JWT 签发/校验、刷新令牌）集中在 `app/security.py`；目录结构清晰体现 `routers → services → models/db/security/config` 的单向依赖方向。
