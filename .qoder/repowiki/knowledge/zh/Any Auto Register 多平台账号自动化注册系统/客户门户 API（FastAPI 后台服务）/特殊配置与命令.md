启动入口为 `python -m customer_portal_api.main` 或 `uvicorn customer_portal_api.main:app --host 0.0.0.0 --port 8100`；首次启动会自动创建 SQLite 数据库并注入权限、角色、管理员账户及平台种子数据；运行参数通过环境变量控制：`PORTAL_JWT_SECRET`、`PORTAL_ACCESS_TOKEN_TTL_SECONDS`、`PORTAL_REFRESH_TOKEN_TTL_SECONDS`、`PORTAL_ADMIN_USERNAME/PASSWORD/EMAIL`、`PORTAL_CORS_ORIGINS`、`PORTAL_DATABASE_URL`；容器化通过根级 `docker-compose.yml` 与 `Dockerfile` 编排。
