模块以 `src/main.tsx` 为入口，使用 `react-dom/client` 挂载 `<App />`；`App.tsx` 内聚路由（`react-router-dom`）、侧边栏导航、主题状态与登录守卫，并通过 `BrowserRouter` + `Routes/Route` 将 `/`、`/accounts/:platform`、`/register`、`/history`、`/proxies`、`/settings` 映射到 `pages/` 下的页面组件。UI 层采用 Radix UI 原子组件（dialog、dropdown-menu、select、tabs、toast）配合 Tailwind CSS v4（`@tailwindcss/vite` 插件），样式通过 CSS 变量（如 `--bg-base`、`--accent`）实现亮/暗/系统主题切换。业务逻辑集中在 `lib/`：`utils.ts` 封装 `apiFetch`/`apiDownload` 统一处理 Bearer Token、401 自动登出与下载；`app-data.ts` 缓存平台列表；`config-options.ts` 定义配置项元数据；`tasks.ts` 与 `registration.ts` 提供任务与注册流程辅助。组件按职责分目录：`components/ui` 为可复用基础控件（button/card/badge），`components/settings`、`components/tasks`、`components/UpdateBanner` 为领域组件。构建产物输出至 `../static` 供后端直接托管，开发时通过 Vite proxy 将 `/api` 转发到 `localhost:8000`。
