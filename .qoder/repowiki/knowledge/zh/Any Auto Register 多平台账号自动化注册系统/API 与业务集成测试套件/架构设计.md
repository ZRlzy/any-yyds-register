测试以 `conftest.py` 为共享入口：在应用导入前通过临时文件 SQLite（`check_same_thread=False`）替换 `core.db.engine`，并用 `_reset_db` 自动夹具在每个用例前后 drop/create 全部表实现数据库隔离；`client` 夹具提供带干净库的 `fastapi.testclient.TestClient` 用于 HTTP 层断言。测试按功能域分文件组织：`test_api_*.py` 针对 `/api/*` 路由做端到端请求断言，`test_proxy_providers.py`、`test_sms_provider.py`、`test_tasks_herosms.py` 等直接 import 领域模块进行单元级 mock 测试（使用 `unittest.mock.patch` 拦截外部 HTTP）。测试依赖被测项目的 `main.app`、`core.*`、`application.*`、`infrastructure.*`、`domain.*` 包，形成单向依赖：tests → 应用代码，不反向引用。
