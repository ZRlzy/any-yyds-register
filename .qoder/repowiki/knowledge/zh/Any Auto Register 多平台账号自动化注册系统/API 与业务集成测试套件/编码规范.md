- HTTP 端点测试统一通过 `client` 夹具发起请求，并使用 `resp.status_code` 与 `resp.json()` 进行断言。
- 数据库状态在每个测试前后通过 `_reset_db` 自动夹具重置，保证用例间完全隔离。
- 对第三方网络调用（如 requests）采用 `unittest.mock.patch` 在调用点打桩返回 `MagicMock` 响应对象。
- 需要鉴权的 API 测试通过本地构造无签名 JWT（`alg: none`）作为伪造 token 传入。
- 工厂类（如 `create_proxy_provider`）的异常路径使用 `pytest.raises(RuntimeError, match=...)` 校验中文错误消息。
