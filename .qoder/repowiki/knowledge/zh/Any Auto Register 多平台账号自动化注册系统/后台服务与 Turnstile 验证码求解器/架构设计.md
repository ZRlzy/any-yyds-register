模块由两个相互独立的后台服务组成：
- `task_runtime.py` 实现单进程内任务调度器 `TaskRuntime`，通过 `application.tasks` 的 `claim_next_runnable_task`/`execute_task` 拉取并执行任务，按平台与账号键限制并发，使用守护线程池管理 worker 生命周期。
- `turnstile_solver/` 是独立可执行的 Quart HTTP 服务（端口 8889），由 `solver_manager.py` 以 `subprocess.Popen` 在父进程启动时拉起；`start.py` 作为入口解析命令行参数并调用 `api_solver.create_app` 暴露 `/turnstile`、`/result`、`/` 三个路由。
- `api_solver.TurnstileAPIServer` 维护基于 `asyncio.Queue` 的浏览器池（支持 Playwright Chromium/Chrome/MsEdge 或 Camoufox），每个请求异步创建上下文与页面，注入脚本绕过反爬、拦截无关资源加载，并通过多种策略点击 Turnstile 控件获取 token。
- `db_results.py` 负责任务结果的 SQLite 持久化，`browser_configs.py` 提供 UA/sec-ch-ua 配置表；`solver_manager` 还封装了 Camoufox 二进制自动安装、进程健康检查、失败重试上限（连续 3 次失败停止）、跨平台端口杀进程等运维逻辑。
依赖方向：`solver_manager` → `turnstile_solver/start.py` → `api_solver` → `browser_configs`/`db_results`；`task_runtime` 仅依赖上层 `application.tasks`，两者互不耦合。
