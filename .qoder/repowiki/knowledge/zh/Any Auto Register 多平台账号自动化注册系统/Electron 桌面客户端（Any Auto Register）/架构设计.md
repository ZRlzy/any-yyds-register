模块以 `main.js` 为 Electron 主进程入口，采用单文件架构：启动时先创建无框透明 Splash 窗口，通过 `child_process.spawn` 在资源目录 `resources/backend/backend/` 下拉起 PyInstaller 打包的后端可执行（开发模式跳过），使用 `http.get` 轮询 `http://localhost:8000/api/health` 等待就绪后创建主 `BrowserWindow` 并加载 `http://localhost:8000` 的前端页面；外部链接通过 `shell.openExternal` 交由系统浏览器打开。自动更新仅在 Windows 生产环境启用，通过 `electron-updater` 监听 `update-available` / `update-downloaded` 事件并弹出对话框触发下载与安装。`electron-builder.yml` 配置产物输出到 `dist/`，将 `backend/` 作为 `extraResources` 注入应用资源目录，并按平台分别生成 dmg/zip（macOS）、nsis 安装包（Windows）、AppImage（Linux）。构建脚本 `build-backend.sh` 负责生成后端二进制，由 npm scripts `build:backend` 调用。依赖方向单一：主进程 → 子进程（Python 后端）+ 渲染进程（本地 HTTP 前端），无额外 IPC 层。
